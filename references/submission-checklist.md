# 阶段7：cponline 提交规范与回归校验

## 1. CNIPA 专利业务办理系统（cponline.cnipa.gov.cn）

- 支持 XML / WORD / PDF 三种格式，单文件 ≤50MB；网页版/客户端/移动端
- 推荐官方"WORD转XML编辑器"（系统首页-工具下载）转换后上传，显著降低格式被拒风险

**WORD 直接上传的硬性禁止项（生成器必须规避）：**
```
文档保护/密码、嵌入 TrueType 字体、文本框与自选图形、域对象/超链接/批注、
修订模式、控件/嵌入对象/链接式图片、非规范图片悬浮格式、宏
```
→ python-docx 生成的纯段落文档天然合规；**切勿**用 docx 模板加文本框装饰。

**附图上传**：JPEG/TIF，≤165×245mm，72–300 DPI（用300），TIF 须 Group 4。

**签名**：提交需移动端 APP 扫码签名。

## 2. 在线编辑器 5 标签页 ↔ 底稿结构

| 标签页 | 底稿对应内容 |
|---|---|
| 1 请求书 | 发明名称/发明人（按序）/申请人/IPC/摘要附图指定/文件清单 |
| 2 说明书摘要 | ≤300 字摘要 |
| 3 权利要求书 | 阿拉伯编号权项 |
| 4 说明书 | 名称+五段标题全文 |
| 5 说明书附图 | 图1–图N 文件清单（图号—文件名—说明三列） |

双轨交付：
- `交付文本/`（4 部分合订，适合逐标签页复制）
- `在线提交/`（5 标签页底稿，含请求书著录项与附图清单，一键照抄）

## 3. 请求书著录项要点

- 发明人顺序即署名顺序，与内部定序表一致；职务发明发明人资格由申请人单位审查
- 申请人为主体单位（如医院/高校），费减备案事前完成
- 摘要附图：指定六图中信息量最大的一张（通常图1）

## 4. 生成器架构（scripts/gen_docs.py）

```
内容层  patent_content_*.py（纯数据字典，改稿只动这里）
  ↓
生成层  gen_final.py（4部分交付文本） + gen_submission.py（5标签页底稿）
  ↓
校验层  verify_docs.py（python-docx 重新打开，断言式校验）
```

分层理由：内容与渲染解耦——改内容零风险重跑；校验层用**重新打开文档**
的方式验证，不信任生成过程内存态。

## 5. verify_docs.py 必查断言（真实项目 ALL PASS 版）

```python
# 每件 docx：
1. 全文段落拼接后包含五段标题（技术领域/背景技术/发明内容/附图说明/具体实施方式）
2. 摘要段 len ≤ 300
3. 附图标记双向一致：
   drawings 里的标记集合 == 正文（含 BODY_INTRO）括号标记集合，差集为空
4. 含"附图标记说明"行
5. 不含黑名单词：【待补】/待实测/示意/优先级/风险提示/数据待实测补实
6. 权利要求首字符为 "1." 且编号连续
7. 具体实施方式以"下面结合附图"或"实施例"开头
```

## 7. 提交后程序与期限管理（提交不是终点）

**三个法定截止期限（逾期后果不可逆）**

| 期限 | 时限 | 逾期后果 |
|---|---|---|
| 申请费 + 公布印刷费 | 自申请日起 2 个月内，**或** 收到受理通知书起 15 日内 | 申请视为撤回 |
| 实质审查请求书 + 实审费 | 自申请日起 3 年内 | 申请视为撤回 |
| 授权当年年费 | 收到授权与办理登记手续通知书起 2 个月内 | 视为放弃取得专利权 |

国知局**只在实审期限届满前 3 个月**发《期限届满前通知书》，此前不主动提醒——
必须自建期限表，不能等通知。权利丧失后可在收到通知起 2 个月内请求恢复
（恢复权利请求费 1000 元 + 《恢复权利请求书》）。

**提交时漏勾选项，事后均可补办（不需要撤回重交）**

| 漏勾选 | 补救动作 | 入口 |
|---|---|---|
| 实质审查请求 | 单独提交《实质审查请求书》并缴实审费 | 手续办理 → 实质审查请求 |
| 提前公布 | 单独提交《发明专利请求提前公布声明》 | 手续办理（电子申请提交电子文件） |
| 费用减缴 | 先办"费减备案"（专利事务服务 → 费减备案），再提交《费用减缴请求书》 | 减缴请求须在费用缴纳期限届满日 2.5 个月前提出；申请费减缴原则上应与申请同时提出，事后补办以系统受理结果为准 |

**费用与减缴**：申请费 900 元 + 公布印刷费 50 元；实审费 2500 元。
减缴比例：单个个人或单位减 85%（实审费 375 元）；两个以上共同申请人减 70%（750 元）。
减缴范围：申请费（不含公布印刷费、附加费）、实审费、授权后 10 年内年费、复审费。
在校学生备案可用学生证明或在读证明。

**加速路径及其代价（必须与全部在审申请统筹）**

提前公布 + 同时请求实审 → 初审合格后即进入公布准备，实务中约 3–6 个月收到
《发明专利申请公布及进入实质审查阶段通知书》，比默认路径省约两年半。
代价：公开后该方案即成为**现有技术**，会成为**自己后续或并行关联申请的对比文件**
（自有在先申请无豁免）——多件组合申报时，"是否提前公布"必须与划界结论一并决定，
不能单件孤立决策。

**缴费入口**：cponline → 专利缴费服务 → 网上缴费（输入申请号 → 查应缴 → 生成订单 →
**当日 23 时前**完成支付；支持微信/支付宝/银行卡/对公）。汇款方式须在汇单写明
申请号与费用名称，且每件申请单独汇款。

通知书电子送达，务必开通短信/邮箱提醒并定期登录领取。
