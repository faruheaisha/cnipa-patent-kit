# 阶段7：cponline 提交规范与回归校验

## 1. CNIPA 专利业务办理系统（cponline.cnipa.gov.cn）

- 支持 XML / WORD / PDF 三种格式，单文件 ≤50MB；网页版/客户端/移动端
- 推荐官方"WORD转XML编辑器"（系统首页-工具下载）转换后上传，显著降低格式被拒风险

**WORD 直接上传的硬性禁止项（生成器必须规避）：**
```
文档保护/密码、嵌入 TrueType 字体、文本框与自选图形、域对象/超链接/批注、
修订模式、控件/嵌入对象/链接式图片、非规范图片悬浮格式、宏
```
→ python-docx 生成的纯段落文档天然合规；**切勿**用 docx 模板加文本框装饰。

**附图上传**：JPEG/TIF，≤165×245mm，72–300 DPI（用300），TIF 须 Group 4。

**签名**：提交需移动端 APP 扫码签名。

## 2. 在线编辑器 5 标签页 ↔ 底稿结构

| 标签页 | 底稿对应内容 |
|---|---|
| 1 请求书 | 发明名称/发明人（按序）/申请人/IPC/摘要附图指定/文件清单 |
| 2 说明书摘要 | ≤300 字摘要 |
| 3 权利要求书 | 阿拉伯编号权项 |
| 4 说明书 | 名称+五段标题全文 |
| 5 说明书附图 | 图1–图N 文件清单（图号—文件名—说明三列） |

双轨交付：
- `交付文本/`（4 部分合订，适合逐标签页复制）
- `在线提交/`（5 标签页底稿，含请求书著录项与附图清单，一键照抄）

## 3. 请求书著录项要点

- 发明人顺序即署名顺序，与内部定序表一致；职务发明发明人资格由申请人单位审查
- 申请人为主体单位（如医院/高校），费减备案事前完成
- 摘要附图：指定六图中信息量最大的一张（通常图1）

## 4. 生成器架构（scripts/gen_docs.py）

```
内容层  patent_content_*.py（纯数据字典，改稿只动这里）
  ↓
生成层  gen_final.py（4部分交付文本） + gen_submission.py（5标签页底稿）
  ↓
校验层  verify_docs.py（python-docx 重新打开，断言式校验）
```

分层理由：内容与渲染解耦——改内容零风险重跑；校验层用**重新打开文档**
的方式验证，不信任生成过程内存态。

## 5. verify_docs.py 必查断言（真实项目 ALL PASS 版）

```python
# 每件 docx：
1. 全文段落拼接后包含五段标题（技术领域/背景技术/发明内容/附图说明/具体实施方式）
2. 摘要段 len ≤ 300
3. 附图标记双向一致：
   drawings 里的标记集合 == 正文（含 BODY_INTRO）括号标记集合，差集为空
4. 含"附图标记说明"行
5. 不含黑名单词：【待补】/待实测/示意/优先级/风险提示/数据待实测补实
6. 权利要求首字符为 "1." 且编号连续
7. 具体实施方式以"下面结合附图"或"实施例"开头
```

## 6. 交付目录规范

```
专利申请/
├── 00_办理指南与请求书填写清单.docx   （面向办理人的操作指南）
├── 00_著录信息与发明人清单.docx      （六件发明人按序/IPC/摘要附图表）
├── 交付文本/ 01..06.docx             （纯申请文本）
├── 在线提交/ 01..06_在线提交底稿.docx （5标签页）
├── 附图/ 01_*/ 图1..6.jpg            （36张 300DPI）
├── 07_在先专利划界比对表.docx        （内部划界记录）
└── 附图索引.html                     （36图一览）
```
内部工作稿（patent_content_*.py、gen_*.py、draw_*.py）放隐藏工作目录，
**不进交付清单**；旧版工作稿保留作划界/溯源记录。

## 7. 提交后程序与期限管理（转入阶段8）

提交之后的所有内容——受理时间口径、通知书种类与接收确认实操、
15 日推定收到日、三个法定截止期限、漏勾选补办、费用与减缴、
加速路径代价、常见误区 FAQ、官方依据——见
[post-filing.md](post-filing.md)。

**交付时必须一并交代的三句话**：

1. 申请费 + 公布印刷费自申请日起 **2 个月内**缴纳，逾期申请视为撤回（唯一紧急项）
2. 实质审查请求自申请日起 **3 年内**提出，国知局只在此期限届满前 3 个月提醒一次
3. 通知书以电子形式送达，**自发出之日起满 15 日即推定为收到日**，
   须开通提醒并定期登录领取，不能等通知
