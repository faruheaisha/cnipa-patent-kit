# 阶段4：撰写规范（依据《专利法实施细则》2023 第20-23条）

## 1. 文档骨架（每件一份，顺序固定）

```
发明名称（居中，黑体16pt加粗）
说明书摘要          ← ≤300字（脚本断言）
权利要求书          ← 阿拉伯数字编号 1. 2. 3. ...
说明书（黑体15pt标题）
  发明名称（再次居中）
  技术领域
  背景技术
  发明内容
    （一）要解决的技术问题
    （二）技术方案
    （三）有益效果
  附图说明
  具体实施方式
```

## 2. 发明名称

- 简明准确表明主题和类型，**一般不超过 25 字**（结构性硬约束弱、一致性硬约束强：
  全套材料同批申请，名称风格必须统一）
- 不得含人名/地名/商标/型号/商品名/商业宣传语
- 推荐"结构或方法特征 + 功能或用途"句式：
  例"一种具有宽温域自润滑功能的多孔复合涂层及其制备方法"
- 类型后缀规则：装置+方法类→"…装置及方法"；产品+制备类→"…及其制备方法"；
  算法类→"…方法及系统"

## 3. 说明书摘要

- ≤300 字（含标点；用 `len()` 断言，不估算）
- 只写：发明点（独立权利要求的核心特征）+ 主要用途 + 相比现有技术的关键效果
- 不出现："本发明具有以下有益效果：第一…第二…"式罗列、具体数值参数
  （精确数留在正文：摘要写"显著优于对照频段"，正文写"目标频段指标≥阈值"的完整指标式）
- 不使用商业宣传语；"该发明/本发明"称谓统一

## 4. 权利要求书

- 阿拉伯数字编号（1. 2. 3.…），独立权利要求在前、从属在后
- 引用附图标记必须加括号：`处理器（8）`；权利要求书正文中不得出现
  "如说明书…部分所述""如图N所示"等引用语
- 独权 = 前序部分（与最接近现有技术共有的必要特征）+ 特征部分
  （区别特征，用"其特征在于"衔接）
- 从权用"根据权利要求N所述的…，其特征在于…"；引用基础正确（不得引用未出现的权项）
- 参数限定：可用范围/比值/功能性限定；**不写【待补】**——数值没到位就改用
  功能性限定（"亥姆霍兹共振且共振频率位于X-YkHz"）
- 疾病诊断红线：权项终点必须是物理量/参数/状态，禁止"诊断/判定患病"式终点

## 5. 说明书五段写法

**技术领域**：1-2 句，写大类+小类（对应 IPC 主分类号），不写具体方案。

**背景技术**：
- 客观描述现有技术及其不足，不贬低、不写商业对比
- 引用本团队已发表论文时用"本发明人所在团队已公开…"句式 + 明确指出
  该文献"未解决本发明所要解决的X问题"（既做研究基础声明又做新颖性铺垫）
- 流行病学/标准数据写明依据（GBZ 49-2014 语频定义等）；每条引用可溯源

**发明内容**：三小节结构（技术问题/技术方案/有益效果）。技术方案与权利要求
**逐条对应**：独权内容先完整复述，再"进一步地，…"逐条展开从权。
有益效果与区别特征一一对应，可写机理但数值性效果必须与实施例一致。

**附图说明**：
- 逐图编号："图1 为…的结构示意图；图2 为…的流程图；…"
- 末尾附**附图标记说明**行：`图中：1-基体；2-感知单元；…`
- 附图中出现的标记必须在此列出，且正文使用时带括号

**具体实施方式**：
- 开头固定引导段："下面结合附图对本发明作进一步说明。如图1所示，本实施例的…包括…（1）…（2）…"
  ——作用：让每个附图标记在文字部分**首次出现即带括号编号**（满足细则21条
  "文字部分未提及的标记不得在附图出现"）
- 至少 1 个能重复实施的完整实施例；关键参数给范围+选择依据+测试条件；
  覆盖替代结构（实施例2/3：变体、异常工况、退化处理）
- 涉算法的实施例必须写：具体输入→处理步骤→输出→与硬件共同产生的技术效果
- 实施例数据口吻：允许示例参数，但保持"某岗位/某工人/本实施例中"假设示例口吻；
  不得写成实验报告风（"实测结果显示…"）
- 效果数据用"在本发明人所依托的项目中…"引出，与内部溯源记录对应

## 6. 排版（python-docx 落地参数）

| 元素 | 设置 |
|---|---|
| 正文 | 宋体 12pt，1.5 倍行距，首行缩进 24pt |
| 节标题（说明书摘要/权利要求书/说明书） | 黑体 15pt 加粗独占一行 |
| 发明名称 | 黑体 16pt 加粗居中 |
| 页边距 | 上2.5 下2.5 左3.0 右2.5 cm |
| 权利要求段落 | 无首行缩进 |

中文字体必须同时设 `run.font.name` 与 `rFonts.set(qn('w:eastAsia'))`，否则中文回退默认字体。

## 7. 自动校验点（写进 verify 脚本，交付前必跑）

```
□ 摘要 len() ≤ 300
□ 五段标题齐全且顺序正确
□ 附图标记双向一致：附图说明列表 = 正文括号标记集合（差集为空）
□ 权利要求编号连续且引用基础正确
□ 全文无【待补】/待实测/示意/优先级/风险提示
□ 名称无禁用词（人名/地名/商标词——按内部名单 grep）
□ 每件 docx 打开无异常、段落数 > 阈值（防生成截断）
```
