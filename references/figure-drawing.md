# 阶段5：专利附图绘制（matplotlib 黑白线条）

## 1. CNIPA 官方格式硬约束

| 项 | 要求 |
|---|---|
| 文件格式 | JPEG 或 TIF（TIF 压缩须 Group 4） |
| 尺寸 | ≤165mm × 245mm（含图题） |
| 分辨率 | 72–300 DPI（**一律用 300**） |
| 颜色 | 黑白线条图，无灰度填充、无彩色 |
| 图题 | 仅"图N"+名称，置于图下方居中 |
| 内容限制 | 不得含无关注释（"示意图/待实测/数据来源"等一律禁止） |
| 流程图 | 方框内仅必需词语；是/否分支标签规范放置 |

## 3. draw_helpers.py API（自动布局，防重叠的核心）

| 函数 | 用途 | 关键设计 |
|---|---|---|
| `chain(ax,x,y_top,items,dias=())` | 垂直流程链自动等间距布局 | 传入菱形下标集合自动切换菱形/矩形，自动画相邻箭头，**杜绝手工坐标错位** |
| `fbox(ax,cx,cy,w,h,text)` | 方框 | `fit_fs()` 自动缩号：文字超框宽92%按比例缩字号，**杜绝文字溢框** |
| `diamond(ax,...)` | 判断菱形 | 文字按菱形内接宽度（0.62×w）缩号 |
| `elbow(ax,pts)` | 曼哈顿折线走线 | 仅末段带箭头，**连线不再斜穿图形** |
| `side_box(ax,src,x2,...)` | 菱形右分支侧框 | 标签自动放线上方 |
| `yes_no(ax,x,y,s,side)` | 是/否标签 | side='r'水平出口上方 / side='d'竖直出口右侧，**位置全局统一** |
| `ref2(ax,num,px,py,tx,ty)` | 标号引出线 | 先垂直后水平，编号白底垫片，**数字不压图形** |
| `lead(ax,...)` / `txt` / `line` / `legend2` | 引线/文字/线段 | 编号融入名称文字时用 lead+txt |
| `figlabel(fig,text)` | 图题 | 图下方居中 |
| `save(fig,pat,num)` | 保存 | 输出 `附图/<专利>/图N.jpg`，300 DPI |

中文字体：`SimHei / Microsoft YaHei`；负号修正 `axes.unicode_minus=False`。

## 4. 每件专利标准图组（6 张模板）

1. **图1 装置总体结构图**：核心图。部件+连接关系，每个部件带附图标记，
   标记体系以此图为准
2. **图2 布置/放大图**：关键结构放大（如多级结构、麦克风布置）
3. **图3 核心流程图**：chain() 主流程 + diamond() 判断 + side_box() 分支
4. **图4 计算/校准流程图**：公式步骤链
5. **图5 状态/对比图**：实施例变体对比（单空腔vs多空腔vs梯度）
6. **图6 曲线对比图**：频率为横轴（log 刻度 500–8000Hz）、衰减/系数为纵轴；
   本发明实施例 vs 对照样品曲线 + 频段区间竖虚线标注

算法类专利可整件全用流程图（图1=总体流程、图2=数据结构、图3=求解流程…）。

## 5. 编号一致性纪律（审查必查）

- **同一标记全文同义**：处理器在图1 是 8，那么图3/图4/正文/权利要求里全部是 8
- 多张图有同名部件时，以图1 体系为准回改其他图；新增部件从当前最大编号续排
- 权利要求中引用标记必须加括号；说明书文字部分首次出现必须带括号

## 6. 曲线图（图6）数据纪律

- 没有实测数据时：画**特征示意**（曲线形态、相对关系正确），数据数组集中在脚本顶部
  一处定义，注释"实测后替换"
- 交付文本中不留"待实测"字样（图内图题也不留）——待办记录在内部工作稿
- 实测到位后只改数组重绘，5 分钟出图

## 7. 常见重叠/漂移 bug 与修法（全部实战踩过）

| 症状 | 根因 | 修法 |
|---|---|---|
| 文字压框线 | 手写坐标未估宽 | 用 fbox（自动 fit_fs 缩号） |
| 侧框标签漂出框顶 | y 手工排布紧贴 | chain() 统一间距；框顶预留 ≥2mm |
| "是"标签与菱形重叠 | 标签位置随手写 | yes_no() 统一位置 |
| 引线穿模 | 斜线直连 | ref2()/elbow() 曼哈顿走线 |
| 曲线与区间虚线相交 | 标注文字放曲线峰上 | 标注移到轴下方或空白象限 |
| 图题与图重叠 | fig.text y 太高 | figlabel 固定 y=0.025 |
| 坐标负号变方块 | unicode_minus | 已在模块内修正 |
