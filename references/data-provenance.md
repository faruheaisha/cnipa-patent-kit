# 阶段6：数据溯源审核（三级标注法）

## 目的

申报材料中的每个数值声明都应能回答"这个数从哪来"。审查答辩、对外宣称、
学术诚信三条线都依赖这张账。核心原则：**宁可标 C，不可虚标 A**。

## 1. 提取：把全部数值声明句捞出来

用 `scripts/extract_claims_data.py`：
- 输入：六件专利的内容字典（embodiment/effect/solution/problem 四个字段）
- 正则：`r'(\d+(?:\.\d+)?\s*(?:千赫兹|kHz|Hz|分贝|dB|帕|Pa|毫米|mm|%|倍|人|名|例|次|秒|小时…))'`
- 按句切分（`。；` 为界），只保留含单位数字且长度>5 的句子
- 输出：按专利分组的声明句清单（真实项目提取出 31 项）

## 2. 建立核对语料

把项目自产材料一次性转纯文本（zipfile 解 docx/pptx/xlsx → 正则剥标签 → html.unescape）：
- 商业计划书、答辩问答库、决赛提问表、推荐信
- 各版 PPT（保留 slide 编号注释便于回查）
- 注意：PDF 直接 read() 会得到二进制乱码（跳过或用 pdfplumber）

## 3. 三级标注

| 级 | 定义 | 处理 |
|---|---|---|
| **[A]** | 自产材料有出处（PPT/BP 逐字或模糊对应） | 引出处文件+原文摘录；模糊对应（"三千余"↔"3500人"）注明换算关系 |
| **[B]** | 文献/标准有出处（论文 DOI/PMID、国标号） | 记录题录；若本地无论文全文，注明"数值对应关系以已写入引用句为准" |
| **[C]** | 材料与文献均无 → 实施例演示参数/示例算例 | **合法但须管口吻**：保持"某岗位/某工人/本实施例中"假设示例；禁止实验报告风（"实测结果显示…"） |

## 4. 专项检查

- **同值不同义陷阱**：不同材料中相同数字可能语义完全不同（真实案例：
  同一百分数在 PPT 中指"某症状共患率"，在商业计划书中指"发生率增幅"）
  ——分别标注，勿混用
- **强断言扫描**：对 [C] 项所在句扫描强断言词（实测/结果显示/验证/统计），
  命中即提示软化措辞
- **文献自证边界**：实测类指标（灵敏度/检测限）若仅见于比赛材料，须在内部记录
  "文献未公开，出处仅为本项目实测"，并确保文本用"在本发明人所依托的项目中"句式
- **关联申请核对**：结构类参数（厚度/密度/孔结构等）若与关联申请载体相关，
  索取其说明书核对——既补出处又完成相互划界

## 5. 输出物：溯源核对表

```
| 数据/声明 | 出处（文件+原文摘录） | 结论 |
```
尾部附：风险分级与处理建议（高/中/低）、待办决策点、文献题录清单。
示例归档名：`数据溯源核对表_YYYYMMDD.md`

## 6. 决策规则

- [A]/[B] 项：正常保留
- [C] 项且口吻安全：**维持现状**（实施例数据不需要出处）
- [C] 项且口吻强断言：软化措辞后重跑生成器+回归校验
- [待核] 项：列为决策点交给用户，不擅自删改
