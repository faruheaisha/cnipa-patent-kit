# 匿名化实战案例：多件发明专利组合全流程（2026-09）

> 本案例已脱敏：不含真实申请人、发明人、申请号、在先专利参数与任何技术细节数值。
> 记录完整决策链，供同类项目参照方法论。

## 项目背景

某高校团队围绕"硬件 + 数据"的真实技术项目，设计 6 件可相互调用数据但各自独立的
发明专利，形成 **监测→防护→匹配→验证→调整→质控** 闭环（环节名称已抽象化）：

| # | 环节 | 类型 | 保护对象（抽象描述） |
|---|---|---|---|
| 01 | 感知监测 | 装置+方法 | 传感阵列、伪差识别、在位校准 |
| 02 | 选择性防护 | 产品+制备 | 频段选择性声学结构 |
| 03 | 参数匹配 | 方法+系统 | 环境参数+个体参数→器件物理参数 |
| 04 | 适配验证 | 装置+方法 | 实际性能与缺陷检测 |
| 05 | 持续调整 | 方法+系统 | 用量计算与参数动态更新 |
| 06 | 现场质控 | 装置+质控 | 非标准条件下测量有效性控制 |

**组合设计启示**：每件类型错开（装置/产品/方法/系统），环节间"数据调用"关系
写成独立权利要求体系而非同一件——既扩大保护面又互不抵触。

## 在先专利划界（5 件本单位在先专利，全部构成现有技术）

关键发现与对策（数值已抽象化）：
- 在先专利的**材料参数与参数区间**与本申请实施例高度重合
  → 涉事专利整体重构：独权换保护客体（材料→器件多级结构）、指标换体系
  （系数→平均衰减量+两频段差值阈值）、参数改功能性限定、新增新用途权项
- 在先方法专利以"特征A+模型B"为必要特征 → 新申请避开该特征组合，
  换用三个不同的输入源组合
- 在先装置专利以"过程量"判配合度 → 新申请改用客观物理判据
- **术语黑名单 12 词**（在先专利核心自定义术语，本申请全文禁用——
  具体词表属内部工作稿，机制见 references/prior-art-mapping.md 第 4 节）

## 撰写规范落地

- 摘要压缩：4 件初稿超字数（309-349 字）→ 压至 255-285 字
  （把精确数值移入正文，摘要只留发明点）
- 附图标记正文提及缺口修复：4 件存在标记仅在附图说明出现、正文未带括号提及
  （违反细则21条）→ 每件加"下面结合附图…包括（1）（2）…"结构总述引导段，
  自动校验 0 缺失
- 【待补】清除：凡数值未到位的权项，一律改功能性限定或"依标准方法测量获得"句式

## 附图（36 张）

- matplotlib Agg + SimHei，160×105mm 画布，300 DPI JPEG
- draw_helpers.py 自动布局（chain/elbow/fit_fs/ref2/yes_no）消灭全部手工坐标 bug
- 修复实录：图题漂出框顶、标签与菱形+图例双重叠、虚线相交、
  编号跨图不一致（同一部件 3 组编号漂移）→ 全部组件级修复+编号统一解决
- 曲线类附图先用特征示意；文本与图题不留"待实测"，待办记内部工作稿

## 数据溯源（31 个数据点）

- [A] 自产材料 14 项：各版 PPT、商业计划书逐字或模糊对应，注明文件+页码
- [B] 文献 8 篇（均 DOI/PMID）：职业队列研究、材料性能文献、国家标准
- [C] 实施例演示 16 项：示例参数 16 项
  → 维持"某岗位/某对象/本实施例中"示例口吻，合法无需出处
- 同值不同义陷阱：同一百分数在 PPT 与 BP 中含义不同——分别标注
- 疑似关联申请出处 → 列决策点索取关联申请说明书核对

## 流程管理教训（元经验）

1. 内容/生成/校验三层分离：改内容→重跑生成→断言校验，一轮 3 分钟
2. 改文件禁用 Python 内读改写（曾把 400 行文件清成 0 字节，靠 docx 反向重建恢复）
3. 验证必须"重新打开交付物"，不信任生成内存态（曾抓出 2/4 处修正未落盘）
4. 发明人按件定序以内部定序表为准，著录项单独成表（00_著录信息清单）
5. 交付双轨：4 部分合订本（逐标签复制）+ 5 标签页底稿（含请求书+附图清单）
6. **交付物保密**：申请未公开前，专利文本/附图不进公开仓库、公开网盘、
   公开演示材料——先申请后公开
